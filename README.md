# Factory Engineer Academy — Beta 1.0

Web game **solo learning beta**, in Vietnamese, responsive for mobile. Simulated NovaBook Pro electronics/laptop factory. **No backend needed to run online**.

## Run locally
Open `index.html` in your browser. Alternatively, run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## Publish online for free — GitHub Pages
1. Create a **public** GitHub repository, e.g. `factory-engineer-online`.
2. Upload the files from **inside this directory**, at the repository root: `index.html`, `style.css`, `app.js`, `beta.js`, `README.md`.
3. In repo Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, folder **/(root)** → Save.
4. Wait for GitHub Pages to show the public URL at `https://YOURUSERNAME.github.io/factory-engineer-online/` (replace placeholders). The exact URL is generated by GitHub and is not known in advance.
5. Every future commit to `main` republishes the site.

## Cloudflare Pages alternative
Workers & Pages → Create application → Pages → Connect to Git → select repo. Framework preset None, leave Build command empty and output directory set to root (`.`). Deploy, then use the URL provided by Cloudflare. Exact dashboard labels can vary.

## Beta learning modules
- 4 Alpha simulations: SIPOC, QE / Pareto–Fishbone–5 Why / cross-functional process, ME machine downtime, IE line balancing
- 6 added Beta modules: TE debug, SQE 8D/SCAR, NPI PFMEA/ECO, PMC BOM/MRP, QE SPC, Production OEE
- Toolbox knowledge reference, simulated 30-minute shift steps, learning progress, local saving and JSON export
- Multiple-choice Beta missions require >= 2/3 correct to complete. Explanations after each step; replay possible.

## Important limitations
- **Online website** means anyone can access the published URL. This does **not** mean multiplayer. There is no game server, shared state, user accounts, cloud progress or WebSocket synchronization.
- Progress is saved in each browser's localStorage. Clearing browser data will remove it. JSON export is available for Beta learning results.
- Shift model is a simplistic causal educational demonstration, not an engineering-grade factory simulation. Scenarios, numbers, thresholds and tooling are illustrative, not real production instructions.
- XP and completion demonstrate activities in this simulator; they are not validated workplace competency certificates.

## Structure
- `index.html`: entry point
- `style.css`: responsive styles
- `app.js`: original Alpha learning engine
- `beta.js`: added modules, Beta views and extra interactions

## Future multiplayer
Requires an authoritative realtime backend (e.g. Cloudflare Durable Objects + WebSockets), room state, reliable reconnection, account identity, role-based permissions, and appropriate abuse controls. Not included in Beta 1.0.
